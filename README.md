# Aaryan Dhabale — AI/ML Engineer Portfolio

An interactive, responsive 3D portfolio website showcasing AI/ML projects, skills, developer stats, and experience.

## ✨ Features
- **3D Interactive Graphics**: Three.js-powered 3D wireframe globe & constellation sphere with mouse/touch parallax.
- **Theme**: Crisp White & Royal Violet modern light aesthetic with glassmorphism cards and micro-animations.
- **Project Showcase**: Filterable carousel with live tags and interactive 3D card tilt.
- **Digital Universe**: Interactive planetary solar system with orbital tooltips.
- **Developer Stats**: Dynamic GitHub contribution calendar heatmap and skill proficiency indicators.
- **Fully Responsive**: Mobile, tablet, and desktop optimized.

## 🛠️ Built With
- **HTML5**, **CSS3**, **JavaScript (ES6+)**
- **Three.js** for 3D interactive graphics
- **Google Fonts** (Inter, Space Grotesk, JetBrains Mono)
